### 🌎 Renewable Energy Plants in Argentina — Interactive Map

This repository contains an **interactive map** created in RStudio.  
Each dot on the map represents a **renewable energy plant** that was operating in Argentina in 2023.
Each dot will show you the following information about the plant: project name, province and department, energy type, installed capacity (MW), and commercial operation start date.

This visualization focuses on **three renewable energy sources**:
- 💧 **Hydric** — small-scale hydro plants with less than 50 MW of installed capacity  
- 🌿 **Eolic** — wind energy plants  
- ☀️ **Solar** — photovoltaic energy plants  

#### ⚙️ Data Source
The list of renewable energy projects was obtained from the following table published by Argentina’s Ministry of Economy:
🔗 [https://www.argentina.gob.ar/economia/energia/energia-electrica/renovables/plantas-de-energia-renovable-en-operacion-comercial](https://www.argentina.gob.ar/economia/energia/energia-electrica/renovables/plantas-de-energia-renovable-en-operacion-comercial)

#### 💻 How to Open the Map
1. Download the file `mapa_plantas_renovables_interactivo.html`.
2. Open it by **double-clicking** the downloaded file.  
3. The map will automatically launch in your default web browser.
